Современное портфолио программиста в тёмной теме в стилистике GitHub. Сайт демонстрирует профессиональные навыки, проекты и опыт работы.

## 🚀 Быстрый старт

### Вариант 1: Локальный запуск
Просто откройте файл `index.html` в любом современном браузере:

```bash
# macOS
open index.html

# Windows
start index.html

# Linux
xdg-open index.html
```

### Вариант 2: Через локальный сервер
```bash
# Используя Python
python3 -m http.server 8000

# Затем откройте в браузере
http://localhost:8000
```

### Вариант 3: GitHub Pages
1. Загрузите репозиторий на GitHub
2. Перейдите в **Settings → Pages**
3. Выберите ветку `main` и сохраните
4. Сайт будет доступен по адресу `https://yourusername.github.io/repository-name`

## 🛠️ Настройка

### Изменение контактной информации
Откройте `script.js` и найдите объект `portfolioConfig`:

```javascript
const portfolioConfig = {
    email: "your.email@example.com",
    github: "yourusername",
    telegram: "yourusername"
};
```

### Добавление проектов
В файле `index.html` найдите секцию `#projects` и добавьте новый элемент:

```html
<div class="project-card">
    <h3>Название проекта</h3>
    <p>Описание проекта...</p>
    <div class="project-tech">
        <span>JavaScript</span>
        <span>React</span>
    </div>
    <div class="project-links">
        <a href="#" class="btn btn-small">Demo</a>
        <a href="#" class="btn btn-small btn-outline">Code</a>
    </div>
</div>
```
